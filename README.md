# Custom Annotations

## 🔐 @Encrypted Custom Annotation

- **Purpose:** Automatically encrypts and decrypts sensitive data fields.
- **Use case:** Secure fields like passwords, personal info without manual encryption code.

---

## @PreventDuplicate Annotation

- **Purpose:** Detects duplicate values in method responses (collections/arrays).
- **Use case:** Applied on methods to return original data along with duplicates found.
